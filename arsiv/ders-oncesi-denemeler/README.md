# Ders Öncesi Denemeler (Arşiv)

> Bu dosyalar atölye başlamadan önce yapılan basit testlerdir. Derste kullanılmıyor.

| Klasör | Ne olduğu |
|---|---|
| `basit_led_yakma/` | Klasik blink: tek LED'i 1 saniye aralıklarla yakıp söndürür. |
| `Polis_Cakari/` | İki LED ile polis çakarı efekti. |
| `Reaktor_Alarm_Sistemi/` | İki LED ile yavaştan hızlıya artan alarm efekti. |
| `Ozel_ders1/` | Boş şablon dosyası (`int main()` — Arduino standardına uymuyor). |
| `Bootloader/` | MCUSR kaydı ile Arduino'nun neden resetlendiğini okuyan teknik test. |
